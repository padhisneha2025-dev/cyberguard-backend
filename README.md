# CyberGuard Core - AI Threat Triage Engine (Backend)

**Frontend Repository:** https://github.com/padhisneha2025-dev/CyberGuard-frontend

## Overview
CyberGuard Core is an AI-powered, real-time threat detection and triage engine designed to automate SOC (Security Operations Center) workflows. This repository contains the FastAPI backend, which actively processes simulated attacks (phishing and login anomalies), evaluates their severity using machine learning, and streams the results directly to the real-time frontend alert feed.

## Tech Stack
* **Backend Framework:** FastAPI, Python, Uvicorn
* **Database:** SQLite
* **AI/ML Integration:** Scikit-learn (Logistic Regression, TF-IDF Vectorizer), SHAP, Pandas, NumPy
* **Infrastructure:** Ngrok (secure localhost tunneling for live demo data injection)

## Running the Demo Locally

**1. Start the API Server**
Navigate to the root directory and start the FastAPI server:
`uvicorn backend.main:app --reload`

**2. Start the Secure Tunnel**
In a new terminal window, expose the local port to the internet using Ngrok:
`ngrok http 8000`

**3. Connect the Frontend**
Copy the `Forwarding` URL generated by Ngrok and update the `BASE_API_URL` variable in the frontend `simulator.html` file to establish the connection.

## API Documentation
Once the server is running, the automatic interactive API documentation (Swagger UI) can be accessed at:
`http://127.0.0.1:8000/docs`
